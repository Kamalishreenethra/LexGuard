# LexGuard – Advanced Manipulation and Fallacy Detection System

LexGuard is an advanced natural language analysis system designed to detect psychological manipulation, logical fallacies, and credibility risks in textual content. The system combines rule-based linguistic analysis, temporal reasoning, and machine learning–assisted scoring to support critical evaluation of written information.

LexGuard is intended as a decision-support tool for analyzing trustworthiness, not as an automated judgment system.

---

## Project Overview

The objective of LexGuard is to identify subtle manipulation strategies and logical fallacies that are commonly used in persuasive, misleading, or deceptive content. The system analyzes input text and produces a structured report including manipulation type, fallacy detection, trust score, and recommendations for further verification.

The project integrates linguistic fingerprinting, temporal freshness analysis, and advanced pattern matching to provide a comprehensive assessment of text credibility.

---

## Key Features

- Detection of psychological manipulation techniques
- Identification of logical fallacies
- Linguistic fingerprint analysis
- Temporal and freshness analysis of claims
- Trust score generation with risk categorization
- Devil’s Advocate module for counter-arguments
- Historical analysis storage using a database
- REST API for programmatic access

---

## Manipulation Techniques Detected

LexGuard can detect multiple manipulation strategies, including but not limited to:

- Guilt framing  
- Emotional urgency  
- Fear appeal  
- Gaslighting  
- Moral blackmail  
- Love bombing  
- Authority pressure  
- False consensus  
- Victim playing  
- Silent treatment  

---

## Logical Fallacies Detected

The system detects common logical fallacies such as:

- False dilemma  
- Slippery slope  
- Strawman argument  
- Ad hominem attacks  
- Hasty generalization  
- Circular reasoning  
- Appeal to emotion  
- Bandwagon fallacy  
- Appeal to tradition
